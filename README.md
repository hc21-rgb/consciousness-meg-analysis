# consciousness-meg-analysis

This repository contains the analysis codes and associated data files for:

**“The neural basis of consciousness during evening naps measured by MEG: a registered report”** (Hemmi et al., 2026).

The repository includes the following Python scripts, data files, and result files.

## Analysis scripts

### `MakeSurfaceMRI.py`

Performs FreeSurfer cortical reconstruction using `recon-all` and supports manual coregistration of each participant’s structural MRI data.

### `MakeForward.py`

Computes the forward solution using the head model generated by `recon-all` and the transformation file obtained through manual coregistration.

### `MakeNoiseCovariance.py`

Computes the noise covariance matrix separately for each experimental day.

### `PreprocessingEpoching.py`

Preprocesses the raw MEG data by applying notch filtering, band-pass filtering, downsampling, and independent component analysis (ICA), and then creates epochs for each participant.

### `SourceEstimate.py`

Performs source reconstruction, computes power spectral density (PSD) for each source vertex, and outputs the mean PSD within the defined regions of interest (ROIs).

### `Bayesian_confirmatory_analysis_feasibility.py`

Performs the Bayesian linear mixed-effects analysis planned for the confirmatory analysis and assesses the feasibility of the planned model using pilot data.

### `Bayesian_single_participant.py`

Performs Bayesian linear mixed-effects analysis separately for individual participants in the pilot analyses and outputs a result file for the specified participant.

### `Bayesian_sample_size_BF3_BF10.py`

Performs model-aligned Bayesian sample-size estimation for directional Bayes factor thresholds of 3 and 10.

## Data files

### `MetaData_pilot.xlsx`
Contains information required for epoching the pilot data. In this file, values in the “Exp date” field have been replaced with surrogate dates to protect participants’ personal information.

### `Participant_data.csv`
Contains the numbers of experience and no-experience awakenings for participants to be included in the confirmatory analysis.

### `ROIpower_by_epoch_pilot.csv`
Contains mean PSD values within each ROI for each epoch obtained from participants included in the pilot analyses.
