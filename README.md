# consciousness-meg-analysis
This repository contains the analysis code for　“The neural basis of consciousness during evening naps measured by MEG: a registered report” (Hemmi et al., 2026).

The repository includes the following Python scripts:

MakeSurfaceMRI.py
Performs FreeSurfer cortical reconstruction using recon-all and conducts manual coregistration for each participant’s structural MRI data.

MakeForward.py
Computes the forward solution using the head model generated by recon-all and the transformation file obtained through manual coregistration.

MakeNoiseCovariance.py
Computes the noise covariance matrix separately for each experimental day.

PreprocessingEpoching.py
Preprocesses raw data by applying notch filtering, downsampling, and independent component analysis (ICA), and then creates epochs for each participant.

SourceEstimate.py
Performs source reconstruction, computes power spectral density (PSD), and morphs individual source-level PSD maps to a template brain.

GroupAnalysis_TFCE.py
Performs Threshold-Free Cluster Enhancement (TFCE)–based statistical analysis and computes Bayes factors.
